# Paper Toss: Pocket Edition
Paper Toss game ported from Pocket (https://madewithpocket.com/p/H_mZHbxtO) by @jasonsgone — published with permission.
Single-page Emscripten/WASM game; the whole game (WASM + 5.7 MB data) is packed inside the 3 coded data PNGs in assets/ (PTB2 format, CRC-verified).
Live at https://xerohour.github.io/paper-toss/
